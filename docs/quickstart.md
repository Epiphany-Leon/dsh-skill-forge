# 5 分钟快速上手

本文带你在 5 分钟内完成 dsh-skill-forge 的安装、第一次技能锻造和基本使用。

---

## 第 1 步：确认环境

开始之前，确保你已经安装了：

- **DeepSeek Harness** (DSH) 0.1.0-rc.5 或更高版本
- **Node.js** 18 或更高版本
- 一个可用的 DSH **web profile**（已经配置好模型和 API key）

检查 DSH 版本：

```bash
dsh --version
```

如果没有安装 DSH，先按照 [DSH 官方文档](https://github.com/deepseek-ai/deepseek-harness)完成安装和初始化。

---

## 第 2 步：安装插件

在你的 DSH profile 目录（如 `~/.dsh/profiles/web`）下执行：

```bash
pnpm add dsh-skill-forge@github:Epiphany-Leon/dsh-skill-forge
```

然后编辑 profile 的 `package.json`，在 `dsh.profile.bundles` 中添加 `"dsh-skill-forge"`：

```json
{
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-skill-forge"
      ]
    }
  }
}
```

### 本地开发安装（可选）

如果你想从源码安装或参与开发：

```bash
git clone https://github.com/Epiphany-Leon/dsh-skill-forge.git
cd dsh-skill-forge
pnpm install
pnpm build

# 链接到本地 DSH profile
cd ~/.dsh/profiles/web
pnpm add dsh-skill-forge@link:/path/to/dsh-skill-forge
# 然后在 package.json 的 dsh.profile.bundles 中添加 "dsh-skill-forge"
```

---

## 第 3 步：启动 DSH Web

```bash
dsh web
```

浏览器会自动打开 DSH Web 界面。注意观察：

- **右侧边栏**：应该出现「Skill Forge」面板，展示锻造队列和技能库
- **顶部导航栏**：应该出现锻造状态指示器（有进行中的任务时会显示动画）
- **设置页面**：在 DSH 设置中能找到「Skill Forge」配置项

如果面板没有出现，打开浏览器控制台检查是否有报错，常见原因是 profile 配置冲突或依赖版本不匹配。

---

## 第 4 步：手动锻造第一个技能

最简单的上手方式是手动触发锻造。

1. 在 DSH 中和 Agent 完成一段对话，比如让它帮你写一个「快速生成正则表达式」的步骤
2. 对话结束后，点击右侧边栏顶部的 **「锻造当前对话」** 按钮
3. 在弹出的对话框中填写锻造理由，例如「这个正则表达式生成方法很实用，可以复用」
4. 点击「开始锻造」

锻造流程随即启动。你会在右侧边栏的「锻造队列」中看到一个新任务，状态依次变化：

```
提取中 → 生成中 → 验证中 → 迭代中 → 审计中 → 待审核
```

每一步状态变化时，页面右上角会弹出 Toast 通知。

---

## 第 5 步：审核并激活技能

锻造完成后，任务状态变为 **「待审核」**，同时弹出审核弹窗。

审核弹窗包含以下内容：

- **技能元数据**：名称、描述、适用场景、标签
- **技能正文**：完整的 SKILL.md 内容预览
- **验证报告**：五个维度的得分雷达图，以及失败用例详情
- **安全审计**：危险模式检测结果和重复技能检测结果
- **来源摘要**：这段对话的简要总结

仔细检查后，你有三个选择：

- **批准**：技能进入激活状态，立即可以被召回使用
- **驳回**：选择驳回原因（预设选项 + 自定义文本），锻造记录保留
- **取消**：关闭弹窗，稍后在队列中继续处理

点击 **「批准」**，你的第一个锻造技能就正式入库了。

---

## 第 6 步：使用锻造的技能

批准后的技能会自动注册到 DSH 的技能系统中。

### 全部注入模式（默认）

默认配置下（`injectionMode: 'all'`），所有激活的技能都会在每轮对话中注入给 Agent。技能数量少时这种方式简单直接。

### 智能注入模式

当技能数量增多后，建议切换到智能注入模式以节省 token：

1. 打开 DSH 设置 → Skill Forge
2. 将「技能注入模式」改为 `smart`
3. 调整「Token 预算占比」和「最低相关度阈值」到合适的值

智能注入会在每轮对话开始前，根据用户消息的关键词和上下文，动态选择最相关的技能注入，在 token 预算内达到最优效果。

你可以通过以下方式验证技能是否正常工作：

- 开始一段新对话，聊与锻造技能相关的话题
- 观察 Agent 是否引用了锻造技能中的方法或步骤
- 在技能库面板查看该技能的「使用次数」是否增加

---

## 第 7 步：管理技能库

点击右侧边栏的「技能库」标签，进入技能库管理界面。

### 搜索与筛选

- 顶部搜索框支持按名称、描述、标签模糊搜索
- 可以按状态筛选（激活 / 待审核 / 草稿 / 已归档）
- 可以按分类筛选
- 支持按质量分、使用次数、创建时间排序

### 查看详情

点击任意技能卡片打开详情面板，可以看到：

- 完整的技能内容
- 版本历史列表
- 锻造来源记录
- 使用统计与反馈评分

### 版本管理

每个技能的每次修改都会生成一个新版本。你可以：

- 查看任意历史版本的内容
- 回滚到任意历史版本
- 为每次修改填写变更说明

### 反馈收集

每次使用技能后，Agent 可以记录用户对技能的反馈（有用 / 一般 / 无用）。技能库中会展示反馈得分，得分过低的技能会被自动标记，建议重新锻造或归档。
